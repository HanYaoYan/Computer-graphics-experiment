# 计算机图形学实验 - 图形交互系统

## 项目简介

本项目是一个完整的计算机图形学实验系统，实现了二维图形的生成、裁剪、几何变换、区域填充、命令系统、文件保存/加载等核心功能。系统采用Python + Pygame开发，提供了友好的图形用户界面。

## 功能特性

### 1. 二维图形生成
- **点**：支持绘制点，可设置颜色和大小
- **直线**：使用Bresenham算法绘制直线
- **圆**：使用中点圆算法绘制圆
- **曲线**：支持贝塞尔曲线绘制（需要4个控制点）
- **文本**：支持文本绘制，可设置字体大小和颜色

### 2. 图形裁剪
- 实现Cohen-Sutherland线段裁剪算法
- 支持设置裁剪窗口
- 自动裁剪窗口内的图形对象

### 3. 几何变换
- **平移变换**：支持图形对象的平移
- **旋转变换**：支持以指定中心点旋转
- **比例变换**：支持x和y方向的缩放

### 4. 区域填充
- **种子填充**：四连通的种子填充算法
- **扫描线填充**：扫描线算法填充多边形区域

### 5. 命令系统
- 完整的命令模式实现
- 支持撤销（Ctrl+Z）和重做（Ctrl+Y）
- 所有操作都通过命令系统执行

### 6. 文件格式
- 支持保存图形到JSON文件
- 支持从JSON文件加载图形
- 保存完整的图形对象和命令历史

### 7. 图形交互系统
- 友好的图形用户界面
- 工具栏选择不同绘图工具
- 颜色选择器
- 实时预览功能

## 使用说明

### 界面布局

- **左侧区域（800x600）**：主画布，用于绘制图形
- **右侧区域（200x700）**：工具栏，包含工具选择和操作按钮

### 工具使用

1. **选择工具**：选择图形对象（当前版本简化实现）

2. **点工具**：
   - 点击画布任意位置绘制点

3. **直线工具**：
   - 按下鼠标左键确定起点
   - 拖动鼠标到终点位置
   - 释放鼠标完成绘制

4. **圆工具**：
   - 按下鼠标左键确定圆心
   - 拖动鼠标调整半径
   - 释放鼠标完成绘制

5. **曲线工具**：
   - 依次点击4个点作为控制点
   - 系统自动生成贝塞尔曲线

6. **文本工具**：
   - 点击画布位置添加文本（默认文本为"Text"）

7. **裁剪工具**：
   - 按下鼠标左键确定裁剪窗口起点
   - 拖动鼠标确定裁剪窗口大小
   - 再次点击完成裁剪窗口设置

8. **种子填充**：
   - 点击需要填充的区域内部任意点
   - 系统自动填充该区域

9. **扫描线填充**：
   - 依次点击至少3个点形成多边形
   - 系统自动填充多边形区域

### 快捷键

- **Ctrl + Z**：撤销上一步操作
- **Ctrl + Y**：重做被撤销的操作
- **Ctrl + S**：保存当前图形到文件
- **Ctrl + O**：从文件加载图形

### 颜色选择

在工具栏右侧有颜色选择器，点击不同颜色方块即可切换当前绘图颜色。

### 文件操作

- **保存**：点击"保存"按钮或按Ctrl+S，图形将保存为`graphics_save.json`
- **打开**：点击"打开"按钮或按Ctrl+O，从`graphics_save.json`加载图形
- **清空**：点击"清空"按钮清除画布上所有图形

## 算法说明

### 1. Bresenham直线算法
实现了经典的Bresenham直线绘制算法，用于高效绘制直线。

### 2. 中点圆算法
实现了中点圆算法，用于绘制圆形。

### 3. 贝塞尔曲线
实现了基于伯恩斯坦基函数的贝塞尔曲线生成算法。

### 4. Cohen-Sutherland裁剪算法
实现了经典的线段裁剪算法，使用区域码判断线段与裁剪窗口的关系。

### 5. 种子填充算法
实现了四连通的种子填充算法，使用队列实现。

### 6. 扫描线填充算法
实现了扫描线填充算法，用于填充多边形区域。
